# VITALIY OS RollCalc для Kodo

Це готовий проєкт із трьох файлів: `index.html`, `styles.css`, `app.js`.

## Встановлення в Kodo
1. Розпакуй ZIP у програмі «Файли» на iPhone.
2. У Kodo створи/відкрий локальний проєкт і імпортуй усі три файли в одну папку проєкту. Якщо Kodo вже створив шаблон із цими назвами, заміни вміст кожного файлу відповідним файлом із цього архіву.
3. Відкрий саме `index.html` і натисни Preview. Не запускай `app.js` окремо.
4. Якщо Kodo питає доступ до файлів, дозволь доступ до папки проєкту або імпортуй файли у власне сховище Kodo.

## Важливо
- Розрахунки локальні, зовнішні бібліотеки та інтернет не потрібні.
- Для точного розрахунку обов’язково введи довжину відомого ролу замість `0`.
- Історія залежить від того, чи дозволяє середовище Preview локальне сховище браузера. Кнопка CSV дозволяє експортувати збережені записи.
